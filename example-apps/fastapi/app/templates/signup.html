PostHog Integration

When you sign up, the following PostHog actions run:

  • identify_context() - Associates your stable user ID with the request context
  • posthog_client.set() - Sets person properties such as email on the person profile
  • user_signed_up event - Tracks the signup action without PII in event properties

Code Example

# After creating the user
if posthog_client:
    user_id = str(user.id)
    with new_context(client=posthog_client):
        identify_context(user_id)
        posthog_client.set(
            distinct_id=user_id,
            properties={
                'email': user.email,
                'is_staff': user.is_staff,
                'date_joined': user.date_joined.isoformat(),
            },
        )
        posthog_client.capture('user_signed_up', properties={'signup_method': 'form'})
