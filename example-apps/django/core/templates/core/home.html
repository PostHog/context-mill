What this example demonstrates

  • User identification - Users are identified with identify_context() via Django's user_logged_in signal and person properties are set via client.set()
  • Context middleware - PosthogContextMiddleware extracts session and user context automatically
  • Event tracking - Custom events captured with client.capture() without PII in event properties
  • Feature flags - Conditional features with client.feature_enabled()
  • Error tracking - Exceptions captured automatically and manually with client.capture_exception()
