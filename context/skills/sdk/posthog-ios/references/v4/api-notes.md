# posthog-ios 4.x requirements and APIs

- Installs via Swift Package Manager only (`https://github.com/PostHog/posthog-ios.git`); CocoaPods does not publish 4.x.
- Requires Xcode 26 or later and deployment targets of at least iOS 15.0 / macOS 12.0 / tvOS 15.0 / watchOS 10.0.
- `captureAi`, `PostHogEventOptions`, and package traits are available across 4.x.
