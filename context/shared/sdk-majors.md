---
title: Stay on today's SDK major
---

Use today's major of each PostHog SDK below. These instructions and the docs they bundle teach that major, and the next major changes the API. Don't install or upgrade to the next major, and don't write code for its API, even when the package manager offers it or installed source, a changelog or a migration guide shows it.

| SDK | Use | Not |
| --- | --- | --- |
| posthog-node | 5.x | 6 |
| posthog (Python) | 7.x | 8 |
| posthog-go | v1, `github.com/posthog/posthog-go` | v2, `github.com/posthog/posthog-go/v2` |
| Rust | the `posthog-rs` crate, 0.x | the `posthog` crate, 1.0 |
| posthog-ios | 3.x | 4 |
| posthog-android | 3.x | 4 |
| posthog_flutter | 5.x | 6 |
